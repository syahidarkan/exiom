# Memory — gagah

Folder ini untuk menyimpan pelajaran dan catatan penting setelah menyelesaikan task.
Simpan di sini hal-hal yang berguna untuk task sejenis di masa depan.

## Format
Buat file .md per topik, misalnya:
- `client-preferences.md` — preferensi klien yang sudah ditangani
- `lessons-learned.md` — kesalahan dan pelajaran dari task sebelumnya
- `templates.md` — template yang berhasil dipakai

## Aturan
- MAX 50KB total per agent (jaga agar tidak membengkak)
- Tulis singkat dan actionable, bukan log mentah
- Update/hapus yang sudah tidak relevan
